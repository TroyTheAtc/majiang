# 老婆的麻将日记

手机端 H5 输赢记录，数据存浏览器本地。**H5 稳定版 v2.1.2**，鸿蒙端开发以此版本为基线。

## 数据存在哪、怎么不丢

所有数据存在**本机浏览器的 localStorage**（按域名隔离），没有云端。这意味着：

- 清「缓存的图片和文件」**不影响**数据；清「Cookie 及其他网站数据 / 网站数据」会**全部清空**。
- **无痕模式**关掉窗口即清空；**换手机、换浏览器、换域名**都读不到旧数据。
- iOS Safari 对长期没访问过的网站会清理网站数据，建议「添加到主屏幕」使用。

保险做法：在「算账」页点 **数据导入/导出 → 复制 JSON**，粘到微信收藏或备忘录留一份。
距离上次导出超过 14 天时，页面顶部会自动出现「该备份一下了」的提示条（可点「稍后」搁置 3 天）。

删掉过「对象」也不会让备份失效：老记录里的对象名照原样保留、照原样恢复，
导入不再要求「记录里的对象必须还在对象列表里」。

## 底注 与 今日大胡

「搓一把」比早期多了两栏，都**可不填**：

**底注（每底的金额）**——用途只有一个：**让不同量级的牌局可比**。
+500 在 5 元底的桌和 50 元底的桌完全不是一回事，没有这一栏，
按金额的统计会把两种牌局混在一起算。

- 填过一次就会**记住**，下次自动预填（大概率一直打同一个底）。
- 支持小数（如 2.5），保留两位。
- 「算账」页多了 **按底注统计** 一栏，可以分开看不同底注的输赢。同一个底注（含小数）归一组。

**今日大胡**——胡了大牌就随手记一笔（如「清一色、碰碰胡」），自由填写。

- 不做成「有/无」开关或多选：大胡的牌型各地叫法不一（清一色 / 碰碰胡 / 十三幺 / 大三元……），
  写死选项一定漏，让人自己写一句最省事。
- 不预填、不记忆（每天的大胡都不一样，预填反而添乱），最多 40 字。
- 填了会在牌谱列表里显示成一枚金色徽章。

> 兼容性：老记录没有这两个字段，一律算作「底注未填 / 无大胡」，
> 不影响原有金额统计；旧备份导入后也是空值，新备份会带上这两项。

## 移动端适配备注

几处「为机型差异」特意写成这样的地方，改这部分代码前先看一眼，别当成多余写法删掉：

- **生日用三个下拉，不用 `type="date"`**：小米等手机自带浏览器把原生日期控件渲染成日历，
  选年份只能一个月一个月地翻，够不着出生年。`年 / 月 / 日` 三个 `<select>` 在任何浏览器里
  都是滚动列表/滚轮，年份一滑直达。**年份列表顶到今年**（出生年不可能是未来）；
  **月固定 1~12、日按当月天数**，不因为选到今年/本月就把列表砍短——半截列表看着像控件坏了。
- **起卦按钮 `touch-action: none`**：用 `manipulation` 时浏览器仍可能把「按住 + 轻微移动」
  当成滚动抢走手势，一被抢就发 `touchcancel`，蓄力当场作废（部分安卓机上就表现成「长按没反应」）。
- **位移容差 14px**：按住不动时手指本来就会飘几像素；早先「一有 touchmove 就作废」会让蓄力几乎无法完成。
- **屏蔽补发的 mouse 事件**：触摸之后浏览器可能补发一整套 mouse 事件，补发的 `mousedown`
  会把蓄力计时重置到 0（表现是「按满 1 秒也不出结果」），用时间戳兜底忽略。
- **蓄力时长自动降级**：连续 3 次「按了很久却没成卦」就把 1 秒压到 380ms（低于系统长按阈值约 500ms），
  保住「至少能用」。只在当前会话生效，不落盘。

## 启动命令

在项目目录下执行：

```bash
./start.sh
```

或：

```bash
bash start.sh
```

**重启服务**（先停掉占用的端口再启动）：

```bash
./restart.sh
```

或复制到终端（任意目录均可）：

```bash
cd "/Users/troy/Desktop/个人材料/000-宝宝/MAJIANG" && ./restart.sh
```

启动后终端会显示访问地址。

## 网址

| 设备 | 地址 |
|------|------|
| **本机浏览器** | http://localhost:8081 |
| **手机浏览器** | http://\<电脑局域网IP\>:8081 |

手机需与电脑连接**同一 WiFi**，将上面 `<电脑局域网IP>` 换成启动时终端里显示的 IP（如 `192.168.1.100`）。

示例：若电脑 IP 为 `192.168.1.100`，则手机在浏览器输入：

**http://192.168.1.100:8081**

## 手机打不开网页时

1. **确认同一 WiFi**  
   手机和电脑必须连同一个 WiFi（不能一个 WiFi 一个手机热点）。

2. **关掉电脑防火墙对 Python 的拦截**  
   - 打开 **系统设置 → 网络 → 防火墙**（或 **隐私与安全性 → 防火墙**）  
   - 若防火墙已开：点「选项」→ 列表里找到 **Python** 或 **python3**，设为「允许传入连接」；若没有，先跑一次 `./start.sh` 再回来看列表。

3. **确认电脑 IP 没变**  
   终端执行：`ipconfig getifaddr en0`  
   看到的就是本机 IP，手机应访问 `http://这个IP:8081`。

4. **先在本机用局域网地址试**  
   电脑浏览器打开 `http://192.168.x.x:8081`（把 x.x 换成你电脑 IP）。  
   若**电脑上这个地址也打不开**，说明服务没对局域网开放，请用下面的「重启」再试。  
   若**电脑能打开、手机打不开**，多半是路由器做了「终端隔离」或手机/电脑没在同一 WiFi。

5. **运行诊断**（在项目目录执行）：  
   `./check.sh`  
   会显示本机 IP 和端口占用，并提示下一步怎么查。

6. **排除路由器隔离**  
   可试：手机开热点，电脑连手机热点，再在手机浏览器访问 `http://<电脑显示的本机IP>:8081`。若这样能打开，就是家里 WiFi 路由器限制了设备互访。

---

关闭终端或按 `Ctrl+C` 可停止服务。
